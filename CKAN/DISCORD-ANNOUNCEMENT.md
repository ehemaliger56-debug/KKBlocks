## Message (English)

🚀 **KKBlocks 1.0.0 is now available on CKAN!**

Created by Lynx. KKBlocks adds 42 ready-to-place static objects for Kerbal
Konstructs: cubes, drivable 45° ramps, pyramids, cylinders, domes and spheres
in seven sizes (0.5–32 m). Each one has twelve stock TextureSet colours, so
there are 504 combinations you can switch at any time in the KK instance
editor. The original cube names and meshes are unchanged, so existing saves
stay compatible, and no plugin is required.

Requirements are simply KSP 1.12.x and Kerbal Konstructs 1.12.x — no
ModuleManager, no texture packs and no other mods. Visual mods such as
Scatterer, EVE, TUFX or Deferred are optional. The blocks use solid colliders
(ramps are drivable, spheres can roll), one stock-like material, and their
origin is at the bottom centre so they scale upward from the ground.

Release and download: https://github.com/ehemaliger56-debug/KKBlocks/releases/tag/1.0.0

What lives where:
• GitHub holds the mod files and the Release ZIP.
• CKAN holds only metadata: download URL, SHA-256, file size, KSP version,
  dependencies and author — install it directly from the CKAN client once
  it appears in the index.
• The NetKAN metadata PR has been merged, so KKBlocks is now published to
  CKAN-meta and can be installed from the client.

KKBlocks is MIT licensed, so you can use, modify and redistribute it,
including in mod packs, as long as the copyright and license notice are kept.

Join the community Discord for help, builds and future updates:
https://discord.gg/GEjdeqJE6g

No beta is active right now. If a pre-release is published later, CKAN will
mark it as a testing release: stable installs stay on 1.0.0 and players can
opt in through the client's stability filter. Known bugs and work in progress
will be listed in that announcement.

Enjoy building,
Lynx
